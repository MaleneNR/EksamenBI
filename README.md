# Analyse af danske boligpriser (1992–2024)

Dette projekt analyserer danske boligpriser fra 1992 til 2024 med fokus på at identificere de faktorer, der påvirker boligpriser.

## Formål
Formålet er at undersøge betydningen af boligtype, størrelse og antal rum samt at vurdere, om boligmarkedet kan opdeles i forskellige segmenter.

## Data
Datasættet indeholder over 1,5 millioner observationer med information om bl.a. pris, størrelse, antal rum og geografisk placering.

## Metoder
Projektet omfatter:
- Eksplorativ dataanalyse (EDA)
- Dataklargøring og preprocessing
- Machine learning:
  - Lineær regression
  - K-means clustering
  - Klassifikation (Decision Tree)

## Resultater
Analysen viser, at boligpriser påvirkes af flere faktorer, og at markedet er komplekst. Der kan identificeres mønstre og segmenter, men ingen enkelt faktor forklarer prisen alene.

## Teknologier
Python (Pandas, Matplotlib), Scikit-learn og Streamlit.
